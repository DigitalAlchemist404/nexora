# Pieza por Pieza — R5-M

Auditoría local, sin inferencia y de solo lectura, de las predicciones incorrectas de R5-L.2.

```bash
python3 PPP_R5M/r5m_auditoria.py
```

Para inspeccionar el contenido de los archivos incorrectos **solo en la terminal local**:

```bash
python3 PPP_R5M/r5m_auditoria.py --mostrar-contenido
```

Antes de compartir nombres o contenido, revísalos para evitar revelar información privada. No modifica el dataset, predicciones, manifiesto ni servidor.
